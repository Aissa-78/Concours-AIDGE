# Vidéos de test

Placez ici les vidéos locales utilisées pour tester FlowSense, par exemple :

```text
videos_test/entree_01.mp4
videos_test/entree_02.mp4
```

Les vidéos ne sont pas envoyées sur GitHub afin de garder le dépôt léger et de
ne pas publier d'images de personnes. Partagez-les avec l'équipe dans un
dossier Google Drive privé.
